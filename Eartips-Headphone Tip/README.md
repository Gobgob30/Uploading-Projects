Molds for some Headphone Tips

Onshape model to get different sizes using configuration: [Link](https://cad.onshape.com/documents/9dc8d60f0b09497d0b93f3ab/w/fc7a5c83d00d45c8e131c012/e/82d883748434e513f55dc341)

Tired of always losing/damaging the ones I got. So I made a mold to make some silicone tips myself.

Added some features other tips have had but cant find anymore.

1. Ribbed to help hold them in
2. Has fins inside to help with rigidity
3. Can add custom text to the outside

If you are resin printing the model, which you should be, [make sure to clean/cure it properly](https://youtu.be/nFbTO97CyTY?t=50) and apply mold release. 

Make sure its stable and skin safe silicone.
