# OGP Cart Phone Mount

Requires charging module. This can be modified in the backup\* file to fit other modules, just change the charger offset and size to fit your module.

This is made to fit most GMD cart's.

It will charge the newer work phone but requires as a charging pad for the older ones. As long as your personal phone is not too big it should charge normally.

Tolerance's are tight between all the printed parts, this is again editable in the backup\* file if you need to adjust it for your printer.

Multi parted makes replacing broken parts easier and allows for easier printing on smaller printers.

\* If .f3z file are allowed to be uploaded.

# Required Parts

- 20W Charging Module [Amazon Link](https://www.amazon.com/Gikfun-Wireless-Charging-Universal-Interface/dp/B0BRMMYZR2/) | [Aliexpress Link](https://www.aliexpress.us/item/3256805864577670.html)
- Double sided tape at least 1mm thick
- 2 x M2x20mm Screws
- 2 x M2 Nuts
- 2 x M2 Washers
- 4 x M3x16mm
- 4 x M3 Nuts
- 4 x M3 Washers

# Assembly

## Base to Mount

1. Insert the M2 screws with washers into phone mount
2. Placing the nuts in the base and putting the two pieces together, secure the screws with the nuts

## Coil Assembly/Phone Mount

1. Install the module onto the Circuit body
   - Using the double sided tape to secure the module, align it with the printed pins
   - Place the coil on the other side with the provided tape
   - Make sure wire for coil is within the channel

2. Place the coil cover on and the back cover, using the M3 screw/washer to align it
3. Secure the back cover with the M3 screws, nuts, and washers
