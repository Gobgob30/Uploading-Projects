This is a lift for Walmart chip shelves. Was requested to find a solution for the shelf continuously breaking. This is it.

# Required parts

- M2 Screws [Link](https://www.mcmaster.com/90128A177/)
- M2 Washer [Link](https://www.mcmaster.com/91166A180/)
- M5 Screws [Link](https://www.mcmaster.com/91290A224/)
- M5 Nut [Link](https://www.mcmaster.com/90591A260/)

# Assembly Instructions

1. Print the parts.
   - need 2 clamp faces, one of everything else.
   - shelf lift isn't used much, can be used for mismatched shelve heights.
2. Put the M2 washer in to the clamp faces
3. install the M5 nut into to the hex hole, install the screw on the outside.
4. Put the clamp faces into the hex hole, use the M2 screw to lock it into place.
5. M5 screw will be used to clamp unit down.
