Just a simple vaccum puller for 20ml syringes

Can be used to degas liquids but will be based on how much pressure you can get from the sealer/pump.

Plan on using it to draw silicone through molds.

### Vaccum Sealer Version

Uses the jar function on one of the cheap vaccum sealers you can get online.

### Vaccum Pump Version

Uses a 1/4" vaccum hose to pull vaccum from a 20 ML syringe.

### Additional parts

- O-ring, make sure it seals on the syringe even when not vaccummed
