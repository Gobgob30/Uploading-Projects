# Vacuum pump adapter

For a cheap vacuum sealer to be powered by a proper pump.

Don't recommend making for food items.... This is the old one with issue that I decided was resin use only.

## Install Instructions

Find out how the tubing works and either spice into it or completely replace the inbuilt tubing except this, which is what I did.

Find a clear spot or make one by removing things like the pump motor, mine happed to be right where I needed.

Just tape the cutout guide in and cutout to guide, center guide as well, which has the center point so you can center it.
